## A. التسويق والنمو (15)
1. **شارة الإحالة الذهبية** — ظهور وسام بجانب اسم العضو الأكثر دعوة هذا الشهر.
2. **حملة "ادعُ ٣ — اربح شهر"** — لافتة ترويجية متحركة في الرئيسية مع مؤقت تنازلي.
3. **مولّد بطاقة دعوة قابلة للمشاركة** كصورة (PNG) جاهزة لقصص واتساب وX.
4. **رابط دعوة قصير ذكي** (busniss.org/r/XXXX) مع تتبّع المصدر (utm تلقائي).
5. **صفحة هبوط للمدعوّين** — تخصيص اسم المُحيل + خصم ترحيبي.
6. **شريط Exit-intent** — عرض كود خصم قبل مغادرة الزائر.
7. **بريد إلكتروني ترحيبي بسلسلة ٧ أيام** (Onboarding drip).
8. **نشرة "أفضل ٥ مشاريع هذا الأسبوع"** تلقائية كل جمعة.
9. **حملة استرداد** للمستخدمين غير النشطين منذ ٣٠ يوماً (Win-back).
10. **OG Image تلقائي لكل مشروع** بهوية المنصة + شعار الشركة.
11. **شارات Social Proof** ("انضم ٢٣ شخص اليوم") متجدّدة.
12. **A/B testing بسيط** لنصوص CTA الرئيسية.
13. **صفحة قصص النجاح المرئية** مع فيديوهات شهادات.
14. **تكامل واتساب للأعمال** — زر "تواصل عبر واتساب" لكل مشروع.
15. **برنامج السفراء** (Ambassadors+) بنسبة عمولة دائمة على إحالاتهم.

## B. الولاء والتفاعل (12)
16. **مستويات عضوية ذهبية** (Bronze/Silver/Gold/Platinum) حسب النشاط.
17. **نقاط ولاء قابلة للاستبدال** برسوم منصة أو ترقية مؤقتة.
18. **شارات إنجاز موسعة** (أول استثمار، ١٠ متابعين، ٥ دعوات…).
19. **مهام يومية** (Daily Quests) بمكافآت نقاط صغيرة.
20. **شريط Streak** — أيام متتالية لزيارة المنصة.
21. **متجر مكافآت** يستبدل النقاط بمزايا (تمييز إعلان، رسوم مخفضة…).
22. **هدية يوم الميلاد** — نقاط/كوبون آلي.
23. **سحب شهري** لجميع المستخدمين النشطين.
24. **لوحة شرف شهرية** للمستثمرين والمؤسسين.
25. **شهادة تقدير PDF** قابلة للتنزيل عند إنجاز معالم.
26. **نظام مستويات تأثير المجتمع** (Reputation Score مرئي).
27. **تنبيه "اشتقنا لك"** عند غياب ٧ أيام مع كوبون رجوع.

## C. الاستمرارية والاحتفاظ (10)
28. **اشتراك سنوي بخصم ٢٥٪** مع شارة "موفّر".
29. **تجديد تلقائي ذكي** مع تذكير قبل ٧ أيام بقابلية الإلغاء بنقرة.
30. **إيقاف مؤقت للاشتراك** بدل الإلغاء الكامل.
31. **عرض استرداد** ذكي عند نية الإلغاء (خصم ٥٠٪ لشهرين).
32. **ملخص شهري شخصي** لأداء المحفظة عبر البريد.
33. **مركز إنجازاتي** يظهر التقدم بصرياً.
34. **تنبيهات Push للويب** لأحداث المحفظة والمشاريع المتابعة.
35. **مزامنة تقويم** لمواعيد الاستحقاق والاجتماعات.
36. **حفظ تلقائي للمسوّدات** في كل النماذج الطويلة.
37. **قائمة "للقراءة لاحقاً"** للمشاريع والأخبار.

## D. الاستدامة المالية والثقة (8)
38. **خطة دفع بالتقسيط للعضويات** (٣/٦ شهور).
39. **محفظة مكافآت منفصلة** لا تُسحب نقداً بل لرسوم المنصة فقط.
40. **نظام Cashback ٢٪** على رسوم العضوية للأعضاء النشطين.
41. **تقارير شفافية ربع سنوية** عامة (عدد الصفقات، النجاحات، النزاعات).
42. **مؤشر صحة المنصة** مباشر (Uptime + Disputes Resolved).
43. **برنامج Bug Bounty** مصغّر مع لوحة شرف وأوسمة.
44. **مصادقة ثنائية إلزامية** للحسابات الذهبية مع مكافأة تفعيل.
45. **سجل شفاف لكل عملية مالية** يراه المستخدم بنفسه (Audit Log).

## E. النجاح طويل المدى (5)
46. **AI Coach للمستثمر** — توصيات أسبوعية مخصصة.
47. **AI Coach لصاحب المشروع** — تحسين الوصف + تنبيه فرص.
48. **مؤشر "احتمال النجاح"** لكل مشروع بناءً على بيانات تاريخية.
49. **مجتمع مغلق للأعضاء الذهبيين** (Inner Circle) مع جلسات حصرية.
50. **شراكات استراتيجية** مع بنوك/منصات (Trust Strip + صفحة شركاء حقيقية).
